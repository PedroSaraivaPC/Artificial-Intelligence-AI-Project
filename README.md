# Artificial-Intelligence-AI-Project

Third-year, first-semester course from my Bachelor’s degree in Computer Science, focused on advanced machine learning concepts, including neural networks (CNNs, MLPs, etc.), fuzzy and neuro-fuzzy systems, and optimization techniques (PSO, ACO, etc.), applied to real-world problems across multiple domains.

**Achieved a project grade of 90% (18 out of 20).**

I used Python, TensorFlow, Keras, and scikit-learn to develop an image-classification system across three stages, with each stage focused on improving the performance of the previous one. I first built and compared CNN and MLP models from scratch. I then developed a more complex CNN architecture based on VGGNet and compared Particle Swarm Optimization (PSO) and Grey Wolf Optimization (GWO) for hyperparameter optimization. In the final stage, I applied transfer learning using EfficientNetB0, MobileNetV2, and ResNet50V2, while comparing GWO with Grid Search and Random Search for hyperparameter optimization. I then deployed the best-performing model through a Streamlit application.
